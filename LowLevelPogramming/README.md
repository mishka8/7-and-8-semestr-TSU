Низкоуровневое программирование на ассемблере NASM

nasm -f elf64 fileName.asm -o 1.o

ld 1.o -o program


**№1 нулевое задание** - "вывести три числа a, b, c через разделитель. Вывести их в квадратных скобках, окруженных пробелами, через разделитель 
в качестве разделителя один пробел
пример 7 1 3 
вывод [ 7 ] [ 1 ] [ 3 ]



**Первое задание** - "Дано трехзначное число. В нём зачеркнули первую справа цифру и приписали её слева. Вывести полученное число."


**Второе задание** - верно ли, что ладья, расположенная на поле (x1, y1) шахматной доски,  "бьет" поле (x2, y2) (x1, y1, x2, y2 - целые от 1 до 8)
